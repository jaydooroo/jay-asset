# DAA (Defensive Asset Allocation) 전략

> 켈러(Keller)가 고안한 모멘텀 기반 동적 자산배분 전략. 카나리아 자산으로 시장 위기를 조기 감지하고 공격/방어 비중을 자동으로 전환한다.

---

## 개요

| 항목 | 내용 |
|------|------|
| 전략명 | DAA (Defensive Asset Allocation) |
| 기대 연복리 수익률 | 10~15% |
| 리밸런싱 주기 | 월 1회 (매월 말) |
| 난이도 | 고급 |

---

## 카나리아 지표 (시장 위기 신호)

VWO(신흥국 주식)와 BND(미국 채권) 두 ETF의 모멘텀 점수를 **카나리아 자산**으로 사용한다.

| VWO, BND 모멘텀 상태 | 다음 달 SPY 연환산 수익 |
|----------------------|------------------------|
| 둘 다 0 이상 | +12.89 ~ +18.46% |
| 하나만 0 이상 | 중간 수준 |
| 둘 다 0 이하 | **-14.17%** (위험 구간) |

카나리아 신호가 약해질수록 공격 자산 비중을 낮추고 안전 자산으로 피신한다.

## 매수 전략

### 1단계: 카나리아 신호로 공격 자산 비중 결정

```
VWO, BND 둘 다 모멘텀 ≥ 0  →  공격 자산 100%
VWO, BND 중 하나만 ≥ 0      →  공격 자산 50%
VWO, BND 둘 다 모멘텀 < 0   →  공격 자산 0%
```

### 2단계: 공격 자산 비중 투자

모멘텀 점수 상위 6개 ETF에 균등 투자.

### 3단계: 안전 자산 비중 투자

모멘텀 점수가 가장 높은 안전 자산 1개에 전액 투자.

---

## 모멘텀 점수 계산

```
모멘텀 점수 = (12 × 1개월 수익) + (4 × 3개월 수익) + (2 × 6개월 수익) + (1 × 12개월 수익)
```

단기 수익에 높은 가중치를 부여해 최근 추세를 더 민감하게 반영한다.

## 백테스트 성과 (1973.1 ~ 2021.8)

| 지표 | 수치 |
|------|------|
| 초기 자산 | $10,000 |
| 최종 자산 | $7,999,633 |
| 연복리 수익률 | **14.7%** |
| 표준편차 | 9.0% |
| 수익 낸 월 비율 | 69.5% |
| MDD (최대 낙폭) | **-12.0%** |
| 샤프 지수 | 1.12 |

- 포트폴리오 전체가 10% 이상 손실을 본 경우는 2000년대 초반 단 **2번**
- 평균 30%만 안전자산에 투자함에도 MDD가 매우 낮음
- 전략 창시자 켈러 본인도 실제 운용에 이 전략을 사용한다고 밝힘 (2020년 인터뷰)
